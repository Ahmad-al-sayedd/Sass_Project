## About The Project

This project showcases a custom-designed, responsive table built using HTML and Sass. The goal of the project was to create a visually appealing, accessible table that displays structured data effectively across all screen sizes.

With Sass, advanced styling techniques were used to improve readability, layout, and user interaction. Features like color schemes, borders, and hover effects are easily customizable, making the design flexible and adaptable for various use cases—from simple data tables to complex data
